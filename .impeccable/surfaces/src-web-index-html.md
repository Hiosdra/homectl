# homectl panel
Mode: Operate. Local browser application for the owner, desktop first and usable on narrow screens.
User rejected three initial sketches as old admin panels and explicitly chose a modern dark UI. This pinned direction supersedes the earlier concept roll.

## Direction contract
THESIS: A compact peer workspace showing machines, trust and changes as daily tasks. No promotional dashboard or decorative metrics.
OWN-WORLD: Blue-black shell, slate work surfaces, pale cool text, violet selection, mint success and amber attention. Crisp 14px UI typography, 1px rules and restrained 8px controls.
STORY: See the current device and vault state, choose a machine or peer, pair explicitly, review changes and resolve conflicts before applying.
FIRST VIEWPORT: A 208px navigation rail, persistent device/session toolbar, a heading with one primary action, search and a full-width machine list with expandable details. Pairing and conflicts get distinct focused work areas. Signature interaction: two equally weighted version panes resolve into one retained row after choosing a version.
FORM: User-pinned modern dark application; prior seed 8008d4dd and its sketches rejected. Standard web navigation and controls. Motion only on conflict resolution, disabled under reduced motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
